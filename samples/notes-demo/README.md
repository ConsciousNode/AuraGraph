# Notes demo

A plain tile of the first 12 s of the CC BY-SA melodica reference (*Rakes of Kildare*; see `../reference/SOURCES.md`), with pinned notes going both ways. The tile and the grid copy are derived from a CC BY-SA recording, so they are CC BY-SA too.

- `melodica_notes-demo_t0.03-11.95_f30-11000.aura.png`: the tile. Its notes are inside it. Open it in AuraLoom (◫ AuraGraph tile) and they appear as pins, or run `python3 ../../prototype/notes.py <tile>` to list them.
- `melodica_notes-demo_grid.png`: the same tile with the grid, bounds and pins drawn in, for a model, who only sees pixels.
- `NOTES.md`: the notes as text, for when the data chunk can't travel (chat uploads strip it).

The human side here is marked as an example. Kehai's question and answer are real: the answer was checked against the recording, and it corrects the example guess (there is no C5 at 6.0 s; it is an E5).
